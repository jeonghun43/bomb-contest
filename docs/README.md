# Bomb Lab 연습 서버 — 학생 안내

시스템프로그래밍 수업의 **Bomb Lab 과제**를 미리 연습하는 서버입니다. 목표는 하나입니다.

> 수업에서 Bomb Lab 과제가 나왔을 때, **하루 안에 전부 해제할 수 있는 실력**을 만든다.

서버에 SSH로 접속하면 여러분 계정 안에 폭탄들이 준비되어 있습니다. 폭탄은 실제 과제와 **같은 컴파일러, 같은 구조**로 만들어져 있어, 여기서 본 어셈블리를 과제에서도 그대로 만나게 됩니다. 정답은 어디에도 적혀 있지 않습니다. 바이너리를 직접 읽어서 알아내야 합니다.

운영 기간은 **2주**입니다(과제가 나오기 전까지). 기간 밖에는 접속할 수 없습니다.

---

## 1. 접속

받은 카드에 **서버 주소·아이디·비밀번호**가 적혀 있습니다. 아래에서 `bomb07`과 `bomb.example.com`은 예시이니, 여러분 카드의 값으로 바꿔 넣으세요.

기본 접속 명령은 어느 운영체제에서나 같습니다.

```bash
ssh bomb07@bomb.example.com
```

### 1-1. Windows

Windows 10·11에는 SSH가 기본 내장되어 있어 **따로 설치할 것이 없습니다.**

1. 시작 메뉴에서 **PowerShell** 또는 **터미널**을 엽니다. (명령 프롬프트 `cmd`도 됩니다.)
2. 위 `ssh` 명령을 입력합니다.
3. 처음 접속이면 지문(fingerprint)을 묻습니다 → `yes` 입력 후 Enter.
4. 비밀번호를 입력합니다. **입력해도 화면에 아무 글자도 보이지 않는 것이 정상입니다** (●●● 조차 안 보임). 그대로 치고 Enter.
   - 카드의 비밀번호를 복사해 **마우스 오른쪽 클릭**으로 붙여넣으면 편합니다. (`Ctrl+V`는 터미널 종류에 따라 안 될 수 있습니다.)

> **⚠️ WSL(우분투 등)로 접속하지 마세요.** WSL은 DNS가 따로 놀아서 도메인 접속이 "Temporary failure in name resolution"으로 실패할 수 있습니다. **PowerShell·명령 프롬프트·Windows Terminal**을 쓰면 문제없습니다. (꼭 WSL을 써야 한다면 도메인 대신 서버 IP로 접속하세요.)

> 아주 오래된 Windows라 `ssh`가 없다면: **설정 → 앱 → 선택적 기능 → 기능 추가 → "OpenSSH 클라이언트"** 를 설치하거나, [PuTTY](https://www.putty.org/)를 씁니다. PuTTY에서는 Host Name에 `bomb.example.com`, 접속 후 뜨는 `login as:`에 아이디, 그다음 비밀번호를 입력합니다.

### 1-2. macOS · Linux

**터미널**(macOS는 응용 프로그램 → 유틸리티 → 터미널)을 열고 위 `ssh` 명령을 그대로 입력합니다. 지문 확인(`yes`)과 비밀번호 입력은 위와 동일합니다.

### 1-3. 접속 후

- 명령이 성공하면 프롬프트가 `bomb07@...:~$` 처럼 바뀝니다. 이제 서버 안입니다.
- 나갈 때는 `exit` 또는 `Ctrl-D`. 다시 들어오면 이어서 작업할 수 있습니다.

## 2. 내 폭탄들

| 위치 | 폭탄 | 점수 | 해설·힌트 | 다시 받기 |
|---|---|---|---|---|
| `~/drills/d0` ~ `d9` | **개념 드릴** 10개. 각각 3단계로 개념 하나를 연습 (D9는 숨은 단계 포함) | 진도표만 | ✅ | ✅ |
| `~/practice` | **연습 폭탄**. 실제 과제와 같은 6단계 + 숨은 단계 | ✗ | ✅ | ✅ |
| `~/bomb` | **과제형 폭탄**. 실제 과제처럼 1인 1개, 점수와 폭발 감점이 스코어보드에 올라감 | ✅ | ✗ | ✗ |

**권장 순서**: 드릴 D0 → D9 → 연습 폭탄(여러 번) → 과제형 폭탄. 드릴 안내는 [DRILLS.md](DRILLS.md)(`~/drills/*/README.md`에도 있음)에 있습니다.

모든 폭탄은 **여러분만의 것**입니다. 상수와 표가 사람마다 다르게 만들어져 있어, 남의 답은 통하지 않습니다.

## 3. 실행 방법

```bash
cd ~/drills/d0
./bomb                 # 표준 입력에서 한 줄씩
./bomb answers.txt     # 파일에서 한 줄씩, 파일이 끝나면 표준 입력으로 이어서
```

**답 파일을 쓰세요.** `answers.txt`에 푼 단계의 답을 한 줄에 하나씩 적어 두면, 다음 단계만 직접 입력하면 됩니다. 편집기는 `nano answers.txt`. 빈 줄은 무시됩니다.

실행하면 폭탄이 먼저 기록 서버에 접속을 확인합니다. 운영 기간이 아니거나 서버에 연결할 수 없으면 단계를 시작하지 않고 사유를 알려 줍니다.

## 4. 폭발 없이 시험하는 법 — 중요

gdb 안에서 폭발 함수에 중단점을 걸어 두면, 답이 틀려도 프로그램이 죽기 직전에 멈춥니다. **새 단계는 반드시 이렇게 먼저 시험하세요.**

```bash
gdb ./bomb
(gdb) break explode_bomb
(gdb) run answers.txt
```

멈춘 상태에서 `info registers`, `x/...` 로 어떤 값이 비교되었는지 볼 수 있습니다. 이렇게 막은 폭발은 서버에 기록되지 않습니다. 자세한 사용법은 [PRIMER.md](PRIMER.md).

## 5. `bomblab` 명령 — 진도·해설·힌트·다시 받기

```bash
bomblab                    # 내 폭탄과 진도 (● 해제  · 아직  ★ 숨은 단계)
bomblab notes d3           # D3에서 해제한 단계들의 해설
bomblab notes practice 4   # 연습 폭탄 4단계 해설 (해제한 뒤에만)
bomblab hint d5 2          # D5 2단계의 다음 힌트 (1 → 2 → 3 순서)
bomblab new d5             # D5를 새 상수로 다시 받기
bomblab new practice       # 연습 폭탄 새로 받기
```

- **해설**은 그 단계를 해제한 뒤에 열립니다. 풀이가 맞았는지, 더 빠른 길이 있었는지, **과제에서는 이 패턴이 어떻게 나오는지**를 확인하세요.
- **힌트**는 언제든 열 수 있지만, 한 단계에 세 개가 차례로 열립니다. 막혔을 때 1번부터 하나씩 여세요.
- **다시 받기**는 같은 구조, 다른 상수의 새 폭탄을 같은 위치에 설치합니다. 이전 폭탄은 더 이상 기록되지 않으니 답 파일도 새로 써야 합니다.
- 과제형 폭탄(`~/bomb`)에는 해설·힌트·다시 받기가 없습니다. 실제 과제와 같은 조건입니다.

## 6. 기록과 스코어보드

- 해제하거나 폭발하면 그 즉시 서버에 기록됩니다. 별도로 제출할 것이 없습니다.
- 틀리면 `BOOM!!!`이 출력되고 프로그램이 종료됩니다.
- 기록은 **여러분의 접속 계정으로만** 남습니다. 남의 이름으로 기록하거나, 정답 없이 해제 기록을 만들 수는 없습니다(서버가 입력을 다시 판정합니다).

브라우저에서 카드에 적힌 주소(예: `http://bomb.example.com/`)를 열면 스코어보드가 보입니다.

| 표 | 내용 |
|---|---|
| **과제형 폭탄** | 원본 과제와 같은 배점: 1~4단계 각 10점, 5~6단계 각 15점, 숨은 단계 +10점, 폭발 1회 -0.5점(최대 -20점) |
| **드릴 진도** | 드릴별 해제한 단계 수, 연습 폭탄 완주 횟수. 점수·순위와 무관 |

## 7. 연습 규칙

1. **혼자 푸세요.** 답이나 풀이를 공유하면 연습이 되지 않습니다. 막히면 `bomblab hint`를 쓰세요.
2. **생성형 AI에 어셈블리를 붙여넣지 마세요.** 과제와 시험에서는 여러분 혼자 읽어야 합니다. 여기서 연습해 두지 않으면 그때 하루 안에 끝낼 수 없습니다.
3. 서버에 설치된 `gdb`, `objdump`, `readelf`, `nm`, `strings`, 계산기, 종이와 펜, `PRIMER.md`가 실제 과제에서도 쓰는 도구입니다.
4. 다른 학생의 계정·파일에 접근하려 하지 마세요.

## 8. 문제가 생기면

**접속 관련**

- **`Permission denied, please try again`** → 비밀번호 오타이거나, 운영 기간 밖입니다. 비밀번호는 화면에 안 보이니 천천히 다시 입력하세요. 카드 값을 복사해 붙여넣는 것을 권장합니다.
- **`Account has expired`** → 운영 기간 밖입니다.
- **`Connection refused` / `Connection timed out`** → 서버 주소를 잘못 쳤거나 네트워크 문제입니다. 카드의 주소를 다시 확인하세요.
- **비밀번호 분실** → 운영진이 재발급해 줍니다.

**실행 관련**

- **"Could not reach the record server"** → 잠시 후 다시 실행하세요. 해제 기록은 유실되지 않습니다.
- **"This bomb is not active right now: CLOSED …"** → 운영 기간이 아닙니다.
- **"This bomb is not active right now: ERR bad bomb"** → 그 폭탄을 `bomblab new`로 다시 받아서 예전 것이 비활성화되었습니다. 같은 위치에 새 폭탄이 있습니다.
- **`bomblab new`가 실패** → 잠시 뒤 다시 시도하세요. 계속되면 운영진에게 알려 주세요. 실패해도 지금 폭탄은 그대로 쓸 수 있습니다.
