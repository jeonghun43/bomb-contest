# 폭탄 해체 대회 — 참가자 안내

여러분은 대회 서버에 SSH로 접속해, **자기 계정 안에 있는** 폭탄 하나를 해체합니다. 폭탄은 **여섯 개의 단계(phase)** 로 이루어져 있고, 각 단계마다 한 줄의 입력을 요구합니다. 틀린 줄을 넣는 순간 폭탄이 터지고 그 사실이 서버에 기록됩니다.

정답은 어디에도 적혀 있지 않습니다. 바이너리를 직접 읽어서 알아내야 합니다.

---

## 1. 접속

받은 카드에 **서버 주소·아이디·비밀번호**가 적혀 있습니다. 아래에서 `bomb07`과 `bomb.example.com`은 예시이니, 여러분 카드의 값으로 바꿔 넣으세요.

기본 접속 명령은 어느 운영체제에서나 같습니다.

```bash
ssh bomb07@bomb.example.com
```

### 1-1. Windows

Windows 10·11에는 SSH가 기본 내장되어 있어 **따로 설치할 것이 없습니다.**

1. 시작 메뉴에서 **PowerShell** 또는 **터미널**을 엽니다. (명령 프롬프트 `cmd`도 됩니다.)
2. 위 `ssh` 명령을 입력합니다.
3. 처음 접속이면 지문(fingerprint)을 묻습니다 → `yes` 입력 후 Enter.
4. 비밀번호를 입력합니다. **입력해도 화면에 아무 글자도 보이지 않는 것이 정상입니다** (●●● 조차 안 보임). 그대로 치고 Enter.
   - 카드의 비밀번호를 복사해 **마우스 오른쪽 클릭**으로 붙여넣으면 편합니다. (`Ctrl+V`는 터미널 종류에 따라 안 될 수 있습니다.)

> 아주 오래된 Windows라 `ssh`가 없다면: **설정 → 앱 → 선택적 기능 → 기능 추가 → "OpenSSH 클라이언트"** 를 설치하거나, [PuTTY](https://www.putty.org/)를 씁니다. PuTTY에서는 Host Name에 `bomb.example.com`, 접속 후 뜨는 `login as:`에 아이디, 그다음 비밀번호를 입력합니다.

### 1-2. macOS · Linux

**터미널**(macOS는 응용 프로그램 → 유틸리티 → 터미널)을 열고 위 `ssh` 명령을 그대로 입력합니다. 지문 확인(`yes`)과 비밀번호 입력은 위와 동일합니다.

### 1-3. 접속 후

- 명령이 성공하면 프롬프트가 `bomb07@...:~$` 처럼 바뀝니다. 이제 서버 안입니다.
- 나갈 때는 `exit` 또는 `Ctrl-D`. 다시 들어오면 이어서 작업할 수 있습니다.
- **대회 시작 시각 전에는 로그인이 거부됩니다.** 시작되면 열리고, 종료 후에는 새 로그인이 막힙니다.

접속하면 홈 디렉터리에 `bomb/` 폴더가 있습니다.

```bash
cd ~/bomb
ls
# bomb  bomb.c  README.md  PRIMER.md
```

| 파일 | 설명 |
|---|---|
| `bomb` | 폭탄 실행 파일 |
| `bomb.c` | 폭탄의 `main` 소스. 단계 호출 순서만 보이고, 판정 코드는 없습니다. |
| `README.md` | 이 문서 |
| `PRIMER.md` | 리버싱 개념 정리. 대회 중 자유롭게 참고하세요. |

여러분의 폭탄은 **여러분만의 것**입니다. 상수와 표가 사람마다 다르게 만들어져 있어, 남의 답은 통하지 않습니다.

## 2. 실행 방법

```bash
cd ~/bomb
./bomb
```

인자 없이 실행하면 표준 입력에서 한 줄씩 읽습니다. 실행하면 폭탄이 먼저 기록 서버에 접속을 확인하고, 대회 시간이 아니거나 서버에 연결할 수 없으면 단계를 시작하지 않고 사유를 알려 줍니다.

**정답 파일을 쓰는 편이 훨씬 안전합니다.**

```bash
./bomb answers.txt
```

`answers.txt`는 **한 줄에 한 단계**씩 적은 텍스트 파일입니다. 편집기는 `nano answers.txt`를 쓰면 됩니다. 푼 단계까지만 적어 두세요. 파일이 그보다 짧으면 다음 단계를 읽으려다 조용히 끝나며 **폭발하지 않습니다.**

## 3. 기록과 폭발

- 각 단계를 **해제**하거나 **폭발**시키면 그 즉시 서버에 기록됩니다. 별도로 제출할 것이 없습니다.
- 틀리면 `BOOM!!!`이 출력되고 프로그램이 종료됩니다. 폭발은 감점 요인입니다.
- 기록은 **여러분의 접속 계정으로만** 남습니다. 남의 이름으로 기록되게 하거나, 정답 없이 해제 기록을 만들 수는 없습니다.

## 4. 폭발 없이 시험하는 법 — 중요

gdb 안에서 폭발 함수에 중단점을 걸어 두면, 답이 틀려도 프로그램이 죽기 직전에 멈춥니다. **새 단계는 반드시 이렇게 먼저 시험하세요.**

```bash
gdb ./bomb
(gdb) break explode_bomb
(gdb) run answers.txt
```

멈춘 상태에서 `info registers`, `x/...` 로 어떤 값이 비교되었는지 볼 수 있습니다. gdb를 이렇게 쓰는 것은 이 랩의 정석 기법입니다. 자세한 사용법은 `PRIMER.md`.

> 참고: gdb 안에서 폭발을 막고 시험하는 것은 서버에 기록되지 않습니다. 정식 해제는 gdb 없이(또는 폭발 중단점 없이) 정답을 넣어 통과시킬 때 기록됩니다.

## 5. 리더보드

브라우저에서 카드에 적힌 주소(예: `http://bomb.example.com/`)를 열면 전체 참가자의 진행 상황·폭발 수·점수·순위가 실시간으로 보입니다. 대회 종료 30분 전부터는 리더보드가 **고정(freeze)** 되어, 최종 순위는 종료 후에 공개됩니다.

## 6. 대회 규칙

1. **개인전입니다.** 답, 중간 결과, 풀이 방법을 다른 참가자와 공유할 수 없습니다.
2. **생성형 AI 도구 사용은 금지됩니다.** 디컴파일러·챗봇에 코드를 붙여넣어 답을 받아내는 행위 모두 해당하며, 적발 시 실격입니다.
3. **허용 도구**: 서버에 설치된 `gdb`, `objdump`, `readelf`, `nm`, `strings`, `ltrace`/`strace`, 계산기, 종이와 펜, 표준 문서, 배포된 `PRIMER.md`.
4. **금지**: 인터넷 검색, 생성형 AI, 자동 심볼릭 실행/솔버(angr, Z3 등), 다른 참가자 계정·파일 접근 시도.
5. 폭탄 바이너리를 패치하거나 판정을 우회하는 것은 해제로 인정되지 않습니다. 서버가 정답 입력을 다시 확인합니다. **답을 알아내는 것이 목표입니다.**

## 7. 채점

| 항목 | 배점 |
|---|---|
| 해제한 단계 | 단계별 점수 합 |
| 폭발 | 감점 |
| 최종 해제 시각 | 동점자 정렬 (빠른 쪽이 위) |

정확한 점수 규칙은 대회 시작 시 공지합니다.

## 8. 문제가 생기면

**접속 관련**

- **`Permission denied, please try again`** → 비밀번호 오타이거나, 아직 시작 전/종료 후입니다. 비밀번호는 화면에 안 보이니 천천히 다시 입력하세요. 카드 값을 복사해 붙여넣는 것을 권장합니다.
- **`Connection refused` / `Connection timed out`** → 서버 주소를 잘못 쳤거나 네트워크 문제입니다. 카드의 주소를 다시 확인하고, 안 되면 진행요원에게 문의하세요.
- **`WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!`** → 서버를 다시 세운 경우 나올 수 있습니다. 진행요원의 안내에 따라 처리하세요. (임의로 키 파일을 지우지 마세요.)
- **비밀번호 입력이 안 되는 것 같음** → 정상입니다. SSH는 보안상 비밀번호를 화면에 표시하지 않습니다. 그냥 입력하고 Enter를 누르세요.
- **비밀번호 분실** → 진행요원이 재발급해 줍니다.

**실행 관련**

- **"기록 서버에 연결할 수 없습니다"** → 잠시 후 다시 실행하세요. 계속되면 진행요원에게 알리세요. (이 경우 해제 기록은 유실되지 않으며, 다시 실행하면 됩니다.)
- **"This bomb is not active right now"** → 대회 시간이 아닙니다(시작 전 또는 종료).

## 부록: 오프라인 연습 모드 (운영자용)

대회 서버 없이 로컬에서 폭탄을 빌드해 연습할 때는 기본(오프라인) 빌드를 씁니다. 이 모드에서는 서버 대신 현재 디렉터리의 `bomb.log`에 결과가 기록됩니다.

```bash
make SEED=<번호>
./bomb build/seed-<번호>/solution.txt
```
