# 개념 드릴 안내

드릴은 Bomb Lab 과제에 나오는 개념을 **하나씩** 연습하는 작은 폭탄입니다. 실행 방식, 입력 처리, 폭발·해제 함수, gdb 사용법은 실제 폭탄과 똑같고, 단계만 3개입니다.

각 단계는 **그 개념만** 보이도록 짧게 만들었습니다(명령어 8~44개). 과제의 phase에는 여기에 검사가 몇 개 더 붙어 더 길어지는데, 해설의 **"과제에서는"** 부분에 무엇이 더 붙는지 적어 두었습니다. 과제와 똑같은 전체 모양은 연습 폭탄(`~/practice`)에서 봅니다.

| 단계 | 하는 일 |
|---|---|
| 1단계 · 기본 | 그 개념을 가장 단순한 모양으로 |
| 2단계 · 변형 | 같은 개념을 다른 문제 형태로 (과제의 다른 학기 변형 등) |
| 3단계 · 응용 | 앞 드릴의 개념과 섞거나 조건을 하나 더 얹어서 |

단계를 해제하면 `bomblab notes dN`으로 해설이 열립니다. 해설 끝의 **"과제에서는"** 부분을 꼭 읽으세요. 막히면 `bomblab hint dN <단계>`.

다 풀고 나서도 `bomblab new dN`으로 새 상수의 드릴을 받아 **아무것도 보지 않고 다시** 풀어 보세요. 한 번에 풀리면 그 개념은 손에 익은 것입니다.

## 드릴 목록

권장 순서는 D0 → D9입니다. 실제 과제 phase의 순서와 같습니다.

| 드릴 | 개념 | 1단계 | 2단계 | 3단계 | 과제에서 |
|---|---|---|---|---|---|
| **D0** | 도구 기본기 | `.rodata`의 답 (`x/s`) | 비교 직전 레지스터 (`break *주소`, `p $eax`) | 실행 중에 만들어지는 답 (`break strings_not_equal`, `x/s $rsi`) | 전체 |
| **D1** | 문자열 | `strings_not_equal`·`string_length` 읽기 | 길이 검사 + 스택에 조립되는 문자열 (`movabs`, 리틀 엔디언, 카나리) | 입력 길이로 고르는 포인터 배열 | phase 1 |
| **D2** | 산술·비교 | `lea`·`imul`·시프트로 만든 식 | 같은 수의 부호 있는/없는 비교 (`jb` vs `jg`) | 상수 나눗셈 (매직 넘버) | phase 2·4 |
| **D3** | 반복문·배열 | `read_six_numbers` + 두 배 수열 | 다른 점화식 (`+i` 또는 `×(i+1)`) | 앞의 두 값을 쓰는 수열 또는 홀짝에 따라 바뀌는 수열 | phase 2 |
| **D4** | switch | 밀집 switch와 점프 테이블 (`x/5gx`) | `"%d %c"` + case 오프셋 (`sub` 후 `ja`) | 희소 switch (비교문) + fall-through | phase 3 |
| **D5** | 함수·재귀 | 인자 레지스터 읽기 (`%edi`, `%esi`, `%edx`) | `func4` 이진 탐색 재귀 | 두 번 부르는 재귀 + 보존 레지스터 | phase 4 |
| **D6** | 문자·표 | 하위 4비트로 고르는 글자 | 표 값의 합 (int 표, 스케일 4) | 인덱스를 따라가는 배열 (거꾸로 추적) | phase 5 |
| **D7** | 구조체·연결 리스트 | 노드 따라가기 (`x/24wx`) | 번호로 고른 노드의 오름차순 | phase 6의 핵심: `7-x` + 내림차순 | phase 6 |
| **D8** | 이진 트리 | 값의 깊이 (24바이트 노드) | `fun7` 경로 인코딩 | 경로의 값 합 (트리 덤프·추적) | 숨은 단계 |
| **D9** | 숨은 단계 | 몸풀기 | 토큰을 실어 나르는 줄 (`sscanf`의 나머지) | 전역 변수에 달린 답 (`num_input_strings`) + **숨은 단계 진입** | 숨은 단계 진입 |

## 드릴을 마쳤다면

1. `~/practice`의 연습 폭탄을 처음부터 끝까지 풀어 보세요. 숨은 단계까지.
2. `bomblab new practice`로 새 폭탄을 받아 **시간을 재며** 다시 풀어 보세요. 목표는 하루(8시간) 안, 익숙해지면 3~4시간.
3. 자신이 생기면 `~/bomb`(과제형)을 푸세요. 점수와 폭발이 스코어보드에 올라갑니다 — 실제 과제처럼 gdb에서 `break explode_bomb`을 걸고 신중하게.
